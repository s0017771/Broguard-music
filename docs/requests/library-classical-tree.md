# 요청서: 악보집 '클래식'을 시대 → 작곡가 → 곡 → 단계로 찾아보기

- **보내는 곳:** 작곡 세션 (브랜치 `claude/piano-composition-am-gbafho`)
- **받는 곳:** 뮤직랩 원장님 (앱 개발 세션)
- **날짜:** 2026-11-21
- **사용자 요청:** "클래식만 따로 떼어서, 클래식을 누르면 음악의 역사 순으로 나왔으면 좋겠다. 시대(연도)가 나오고, 시대를 누르면 작곡가, 작곡가를 누르면 곡, 곡을 누르면 레벨이 나오는 형식. 다른 악보집은 곡 정렬이지만 클래식은 음악의 역사와 작곡가별로. 그러면 역사도 자연스럽게 알 수 있을 것 같다."

## 1. 배경

- 사용자는 음악사를 공부하며 작곡가를 한 명씩, 곡마다 세 단계 악보(1 인터미디어트, 2 어드밴스, 3 원곡)로 피아노를 연습하려고 합니다. 바흐부터 시작합니다.
- 작곡 세션이 `classical/` 폴더에 악보와 목록 파일 `classical/catalog.json`을 만들고 관리합니다(반딧불 앨범의 `scores/album.json`, 리믹스의 `remixes/album.json`과 같은 방식).
- 지금 `catalog.json`에는 4개 시대, 21명의 작곡가, 바흐의 계획된 15곡이 들어 있습니다. **악보 파일은 아직 없고**(모든 곡이 `"status": "planned"`), 사용자가 한 곡씩 부탁할 때마다 3개씩 생깁니다. 처음에는 가짜 데이터로 개발해 주세요.

## 2. 데이터: `classical/catalog.json`

```json
{
  "collection": "클래식 악보집",
  "category": "클래식",
  "updated": "2026-11-21",
  "levels": [
    {"id": "intermediate", "no": 1, "name": "인터미디어트"},
    {"id": "advanced", "no": 2, "name": "어드밴스"},
    {"id": "original", "no": 3, "name": "원곡"}
  ],
  "eras": [
    {
      "id": "baroque", "name": "바로크", "years": "1600–1750",
      "summary": "여러 선율이 맞물리는 대위법과 일정한 박. …",
      "composers": [
        {
          "id": "bach", "name": "요한 제바스티안 바흐", "shortName": "바흐",
          "years": "1685–1750", "nickname": "음악의 아버지", "status": "in-progress",
          "pieces": [
            {
              "id": "bach-anh114", "title": "미뉴에트 G장조", "work": "BWV Anh. 114",
              "year": "1725", "collection": "안나 막달레나 바흐를 위한 음악 수첩",
              "note": "실제 작곡가는 크리스티안 페촐트", "status": "done",
              "scores": [
                {"level": "intermediate", "id": "classical-bach-anh114-1",
                 "title": "바흐 · 미뉴에트 G장조 [1 인터미디어트]",
                 "file": "bach/minuet-g-anh114-1-intermediate.abc"}
              ]
            }
          ]
        }
      ]
    }
  ]
}
```

- 배열 순서가 곧 보여 줄 순서입니다. 시대는 역사 순, 작곡가는 태어난 순, 곡은 작곡 세션이 정한 학습 순서(쉬운 곡 → 어려운 곡)입니다.
- `scores[].file`은 `classical/` 기준 경로, `scores[].id`는 바뀌지 않는 고정 id, `scores[].title`은 그 `.abc` 파일의 첫 번째 `T:` 줄과 같습니다.
- `status`: `planned`(준비 중), `in-progress`(작곡가 단위, 진행 중), `done`(곡 단위, 악보 있음). 곡의 `scores`에 있는 단계만 실제 악보가 있습니다.
- `nickname`, `note`는 없을 수 있습니다.

## 3. 요청 A — 받기: 클래식 악보도 악보집에 넣기

- 지금의 [🎹 반딧불 앨범 받기]처럼, `classical/catalog.json`의 모든 `scores`를 펼쳐서 악보집에 없는 것만 추가합니다. 버튼을 따로 둘지, 기존 버튼에 합칠지는 원장님이 정해 주세요.
- **카테고리는 '클래식'**입니다('기타'가 아님).
- 이미 있는지 판정, 덮어쓰지 않기, 중복 없음 등의 규칙은 반딧불 앨범 받기와 같습니다(id 먼저, 다음에 정규화한 제목).

## 4. 요청 B — 클래식 찾아보기 화면

악보집(필요하면 플레이어도)에서 '클래식' 분류를 누르면, 가나다 목록 대신 아래 4단계로 찾아 들어갑니다.

1. **시대:** 바로크 1600–1750, 고전 1750–1820, 낭만 1820–1900, 근현대 1900– 를 역사 순으로 보여 주고, 각 시대의 한 줄 설명(`summary`)을 함께 표시합니다.
2. **작곡가:** 이름, 생몰년, 별명(예: "음악의 아버지"), 악보가 있는 곡 수를 태어난 순으로 보여 줍니다.
3. **곡:** 제목, 작품 번호, 연도, 메모를 목록 순서대로 보여 줍니다.
4. **단계:** 1 인터미디어트, 2 어드밴스, 3 원곡. 누르면 지금처럼 악보를 열거나 재생합니다.

- 화면 위에 `클래식 › 바로크 › 바흐 › 미뉴에트 G장조` 같은 경로와 뒤로 가기를 둡니다.
- **목표가 보이게:** `planned` 곡이나 악보가 없는 단계는 흐리게 '준비 중'으로 보여 주면 좋겠습니다. 사용자가 목차를 목표로 삼아 한 곡씩 채워 가려고 하기 때문입니다.
- **목록에 없는 클래식 곡:** 사용자의 악보집에는 예전에 따로 가져온 클래식 곡(제목이 깨진 OCR 곡 포함)이 있습니다. `catalog.json`과 맞지 않는 '클래식' 항목은 맨 끝의 '기타 클래식' 묶음에 지금처럼 가나다순으로 보여 주세요. 사라지면 안 됩니다.
- 악보집 항목과 목록의 연결은 id(`classical-…`) 먼저, 다음에 제목으로 합니다.
- 다른 분류(기타, K-가요 등)의 정렬은 지금 그대로입니다.

## 5. 테스트

- 순수 함수(예: 목록과 악보집 항목으로 트리를 만드는 함수)의 단위 테스트: 시대·작곡가·곡 순서 유지, `planned` 표시, 목록에 없는 클래식 항목은 '기타 클래식'으로 분류, 빈 목록.
- E2E: 가짜 `catalog.json`과 `.abc` 응답으로 받기 → '클래식' 카테고리로 저장, 4단계를 눌러 내려가고 뒤로 가기, 마지막 단계에서 악보 열기.

## 6. 완료 기준

1. '클래식'을 누르면 시대 → 작곡가 → 곡 → 단계 순서로 찾아 들어갈 수 있다.
2. 순서가 목록 파일의 순서(역사 순, 태어난 순, 학습 순)를 따른다.
3. 받기로 추가한 클래식 악보는 '클래식' 카테고리로 저장되고, 여러 번 받아도 중복이 없다.
4. 목록에 없는 기존 클래식 곡도 '기타 클래식'에서 그대로 보인다.
5. 기존 테스트가 모두 통과한다.

## 7. 배포 관련

- `classical/`은 작곡 브랜치 `claude/piano-composition-am-gbafho`에 있습니다. 반딧불 앨범 때처럼 main으로 가져와 주시거나, 사용자의 PR(#123)이 합쳐진 뒤 쓰시면 됩니다.
- 작곡 세션은 곡을 만들 때마다 `catalog.json`의 그 곡에 `scores`를 채우고 `status`를 `done`으로 바꿉니다. 형식을 바꿔야 하면 이 요청서나 작곡 세션 쪽에 알려 주세요.
