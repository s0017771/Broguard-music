    ☁️ 구글 드라이브 동기화 여러 기기에서 같은 악보집

    아직 설정 전이에요. 구글 드라이브에 저장/불러오기로 여러 기기에서 동기화하려면, 무료 구글 OAuth 클라이언트 ID를 발급받아 library.html의 DRIVE_CLIENT_ID 값에 넣어주세요.
    📖 발급 방법 5단계 보기
    1. console.cloud.google.com 접속 → 프로젝트 새로 만들기
    2. 「API 및 서비스 → 라이브러리」에서 Google Drive API 사용 설정
    3. 「OAuth 동의 화면」 구성 → User type: 외부 → 앱 이름 입력 → 테스트 사용자에 내 Gmail 추가 (Testing 상태 유지)
    4. 「사용자 인증 정보 → OAuth 클라이언트 ID 만들기」 → 유형 웹 애플리케이션 → 승인된 JavaScript 원본에 https://broguard-music.vercel.app 추가
    5. 만들어진 클라이언트 ID를 복사해 library.html의 DRIVE_CLIENT_ID = ''에 붙여넣기 → Vercel에 배포

    🔒 drive.appdata 권한만 사용 — 이 앱이 만든 숨김 동기화 파일 하나만 접근하고, 드라이브의 다른 파일은 볼 수 없습니다.
