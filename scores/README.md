# 🎹 반딧불 앨범 — 스물한 곡의 기승전결

> 고된 하루의 퇴근길에서 시작해, 첫눈 내리는 캐럴까지.
> 한 사람의 날들을 담은 피아노 연주곡집입니다.

모든 곡은 **오리지널 창작곡**입니다. 일부 곡은 좋아하는 노래·작곡가의 *스타일*(리듬 문법, 화성 어법, 곡 구조)에서 영감을 받았지만, 멜로디는 전부 새로 작곡했습니다.

## 듣는 법

- 이 저장소의 **악보 연구소(`lab.html`)** 에 `.abc` 파일 내용을 붙여넣으면 악보 렌더링 + 재생이 됩니다.
- abcjs 기반의 어떤 ABC 플레이어(뮤직랩 등)에서도 재생 가능합니다.
- 모든 곡은 양손 2성부(V:1 멜로디 / V:2 반주) + 코드 심볼 + 셈여림 표기를 포함하며, 마디별 박자 합을 스크립트로 검증했습니다.

## 추천 감상 코스

- **하루의 서사로 듣기** — 1 → 3 → 4 → 18 : 퇴근길, 현장, 창업, 그리고 오늘의 엔딩 크레딧까지. 이 앨범의 주인공 이야기 순서.
- **작은 항구 3부작** — 6 → 7 → 8 : 같은 주제가 왈츠 → 브릿지 확장 → 4/4로 변해가는 과정.
- **머무름 연작** — 9 → 12 → 10 : 같은 약속을 낮의 발라드로, 뛰는 심장으로, 밤의 속삭임으로.
- **원판 vs 16비트 비교** — 5↔11, 9↔12 : 음표 밀도가 그루브를 어떻게 바꾸는지.
- **위로 3부작** — 13 → 14 → 15 : 내려놓음(가스펠), 돌아봄(회한), 그리고 해방(앤섬).
- **신나는 코너** — 2 → 16 → 17 → 19 → 21 : 캐논, 폴카, 산책, 봄, 그리고 첫눈의 스윙.
- **통기타와 계절** — 20 → 19 → 21 : 포크의 가을, 봄이 오는 노래, 겨울의 캐럴.

- 대부분의 곡은 **기승전결**(또는 Verse–Chorus 송폼)을 8마디 단위로 설계했습니다.
