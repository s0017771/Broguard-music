# 🎹 반딧불 앨범 — 쉰한 곡의 기승전결

> 고된 하루의 퇴근길에서 시작해, 흥얼거림 속에 남은 노래까지.
> 한 사람의 날들을 담은 피아노 연주곡집입니다.

모든 곡은 **오리지널 창작곡**입니다. 일부 곡은 좋아하는 노래·작곡가의 *스타일*(리듬 문법, 화성 어법, 곡 구조)에서 영감을 받았지만, 멜로디는 전부 새로 작곡했습니다.

## 듣는 법

- 이 저장소의 **악보 연구소(`lab.html`)** 에 `.abc` 파일 내용을 붙여넣으면 악보 렌더링 + 재생이 됩니다.
- abcjs 기반의 어떤 ABC 플레이어(뮤직랩 등)에서도 재생 가능합니다.
- 모든 곡은 양손 2성부(V:1 멜로디 / V:2 반주) + 코드 심볼 + 셈여림 표기를 포함하며, 마디별 박자 합을 스크립트로 검증했습니다.

## 형식 노트

- 대부분의 곡은 **기승전결**(또는 Verse–Chorus 송폼)을 8마디 단위로 설계했습니다.
- 초기 곡(1–10)은 8분음표 격자(`L:1/8`), 11번 이후는 16분음표 격자(`L:1/16`)로 부점·당김음·필인을 살렸습니다.
- 반복해서 쓴 장치들: 단조 주제의 장조 회귀(1, 3), 마지막 코러스 전조(4, 15, 18, 19), 훅의 옥타브 하강 아웃트로(5, 11), 머무는 음(9, 12), 걸음을 그리는 왼손(3, 8, 17).
