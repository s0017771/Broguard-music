# score2abc — 악보 사진·PDF를 ABC 악보로 자동 변환

`inbox` 폴더에 악보를 넣으면 알아서 **ABC 악보**로 바꿔 `output` 폴더에 저장해 주는 프로그램입니다.
뮤직랩(`lab.html`)에 바로 붙여넣을 수 있도록 자동 정리까지 해 줍니다.

```
악보(PDF·사진) → [Audiveris] 악보 인식 → MusicXML → [xml2abc] ABC 변환 → 자동 정리 → .abc
```

## 준비물

| 준비물 | 설명 |
|---|---|
| **Python 3.8 이상** | [python.org](https://www.python.org/downloads/)에서 설치. 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요. |
| **Audiveris 5.x** | [공식 GitHub 배포 페이지](https://github.com/Audiveris/audiveris/releases)에서 설치. OCR 언어팩(영어)도 설치되어 있어야 코드 이름을 읽습니다. |
| **이 폴더** | `score2abc.py`, `xml2abc.py`, `convert_once.bat`, `start_watch.bat`를 한 폴더에 두세요. |

EasyABC는 없어도 됩니다. EasyABC 안에서 변환을 맡는 `xml2abc.py`를 이 폴더에 함께 넣어 두었습니다.

## 사용법 (Windows)

1. **`convert_once.bat`를 더블클릭**하면 처음 한 번 `inbox`, `output` 같은 폴더가 만들어집니다.
2. 악보 PDF나 사진을 **`inbox` 폴더**에 넣습니다.
3. 다시 **`convert_once.bat`를 더블클릭**하면 변환이 시작됩니다. 한 장에 수십 초~몇 분 걸려요.
4. 결과는 **`output` 폴더**의 `.abc` 파일입니다. 메모장으로 열어 전체 복사 → 뮤직랩에 붙여넣기.

악보를 자주 넣을 거라면 **`start_watch.bat`**를 켜 두세요. 창을 열어 두는 동안 `inbox`에 악보가 들어올 때마다 자동으로 변환합니다. 끝낼 때는 창을 닫거나 Ctrl+C.

| 폴더 | 용도 |
|---|---|
| `inbox` | 변환할 악보를 넣는 곳 |
| `output` | 완성된 `.abc` 파일 |
| `done` | 변환이 끝난 원본 악보 |
| `failed` | 변환에 실패한 원본과 로그(`.log`, `.error.txt`) |
| `work` | 작업 중 임시 파일 (자동 정리됨) |

## 자동으로 정리해 주는 것

- **템포 추가**: 템포 표시가 없으면 `Q:1/4=80`을 넣습니다 (없으면 뮤직랩이 아주 빠르게 재생해요).
- **문법 경고 줄이기**: 뮤직랩이 모르는 줄바꿈 기호 `$`와 인쇄용 설정 줄을 지웁니다.
- **코드 복원**: 인식 과정에서 글자 메모로 잘못 들어간 코드 이름(예: `"^G/B"`)을 진짜 코드(`"G/B"`)로 되돌립니다.
- **잘못 읽은 기호 지우기**: 악센트·셈여림·스타카토처럼 잘못 인식되기 쉬운 장식 기호와, 코드가 아닌 글자 조각을 지웁니다.
- **박자표 추정**: 박자표를 못 읽었으면 가장 흔한 마디 길이로 박자표를 채웁니다.
- **줄 첫 마디 코드 빠짐 경고**: Audiveris는 두 번째 줄부터 **각 줄 첫 마디의 코드**를 자주 놓칩니다. 원본 악보에서 줄이 시작되는 마디인데 코드가 없으면 `% ?확인: 원본에서 줄이 시작되는 마디인데 코드가 없어요: 5, 9, 13`처럼 알려 줍니다. 앞 마디 코드가 그대로 이어지는 곳도 걸릴 수 있어서 '의심'으로만 표시해요. 곡 전체에 코드가 거의 없으면 경고하지 않습니다.
- **박자 검사**: 박자가 모자라거나 남는 마디를 찾아 파일 맨 위에 `% ?확인: 박자가 다른 마디: 8`처럼 적어 줍니다. 콘솔 창에도 표시됩니다.
- **멜로디 성부만 남기기**: 성부가 여러 개로 인식되면(`%%score` 줄이 생기면) 맨 위 멜로디 성부만 남깁니다. 뮤직랩의 **줄별 듣기**와 **커서 4마디**는 멜로디 한 줄짜리 악보에서만 동작하기 때문이에요. 2절용 음표처럼 꼬리를 아래로 적은 음표가 따로 인식된 경우도 함께 정리됩니다.
- **한 줄에 4마디**씩 보기 좋게 나눕니다.

## 자동으로 못 고치는 것 (사람이 확인해야 해요)

- **빠진 음표·쉼표**: 인식이 놓친 것은 되살릴 수 없습니다. 대신 박자 검사가 그 마디를 알려 줍니다.
- **빠진 코드 이름**: 특히 줄 첫 마디의 코드를 자주 놓칩니다. 경고에 나온 마디를 원본과 비교해서, 첫 음표 바로 앞에 `"Bb"`처럼 코드를 넣어 주세요.
- **가사**: 가사 인식은 자주 틀립니다. 멜로디와 코드만 쓰신다면 설정에서 `REMOVE_LYRICS = True`로 바꾸세요.
- **도돌이 괄호(1., 2.)**: 인식이 놓치면 반복 구조가 틀어집니다.
- **손글씨·흐린 사진**: 깨끗하게 인쇄된 PDF나 스캔(300dpi 정도)일수록 정확합니다.

테스트로 인쇄 악보 16마디를 변환했을 때 **음표는 16마디 모두 정확**했고, 코드는 16개 중 13개를 읽었으며, 놓친 쉼표 1개는 박자 검사가 찾아냈습니다.

## 설정 바꾸기

`score2abc.py`를 메모장으로 열면 맨 위에 설정이 있습니다.

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `AUDIVERIS_PATH` | `""` (자동) | Audiveris를 못 찾을 때 실행 파일 위치를 적습니다. 예: `r"C:\Program Files\Audiveris\Audiveris.exe"` |
| `DEFAULT_TEMPO` | `80` | 템포가 없을 때 넣을 빠르기 |
| `BARS_PER_LINE` | `4` | 한 줄의 마디 수 |
| `UNFOLD_REPEATS` | `False` | 도돌이표를 펼쳐 쓸지 |
| `REMOVE_DECORATIONS` | `True` | 장식 기호를 지울지 |
| `REMOVE_TEXT_NOTES` | `True` | 코드가 아닌 글자 메모를 지울지 |
| `REMOVE_LYRICS` | `False` | 가사 줄을 지울지 |
| `MELODY_ONLY` | `True` | 성부가 여러 개면 맨 위 멜로디만 남길지. 피아노 왼손까지 살리려면 `False` |

## 문제가 생기면

- **"Audiveris를 찾지 못했어요"**: 위 표의 `AUDIVERIS_PATH`에 설치 위치를 적어 주세요.
- **"Python이 없습니다" 류의 메시지**: Python을 설치할 때 "Add python.exe to PATH"를 체크했는지 확인하고, 필요하면 다시 설치하세요.
- **뮤직랩에서 줄별 듣기 버튼이 안 보이고, 커서 4마디가 "처음부터"로 재생돼요**: 악보에 성부가 여러 개 남아 있다는 뜻이에요. `MELODY_ONLY = True`인지 확인하고 다시 변환하세요.
- **변환이 실패했어요**: `failed` 폴더에 원본과 로그가 있습니다. 로그를 보여 주시면 원인을 같이 찾아볼 수 있어요.
- **Windows에서 인식 단계가 끝나지 않아요**: 일반 설치판 대신 Audiveris 배포 페이지의 `windowsConsole` 설치판을 써 보세요. 명령어 실행용으로 만든 판입니다.
