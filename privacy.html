브로가드 뮤직 랩 (BRG Music Lab)

1. 서비스 개요

브로가드 뮤직 랩(이하 "본 서비스")은 개인 취미 목적의 음악 학습·채보 도구 모음입니다. 본 서비스는 별도의 서버나 데이터베이스를 운영하지 않는 정적 웹사이트이며, 회원 가입 절차가 없습니다.

2. 수집하는 개인정보

본 서비스는 개인정보를 수집하지 않습니다. 사용자가 만든 악보, 재생목록, 설정 등 모든 데이터는 사용자 기기의 브라우저 저장소(localStorage)에만 저장되며, 운영자나 제3자의 서버로 전송되지 않습니다.

3. 구글 드라이브 연동 (선택 기능)

악보집 동기화를 위해 사용자가 직접 "구글 계정 연결"을 선택한 경우에만 Google Drive API를 사용합니다.

  • 요청 권한은 drive.file 하나로, 본 서비스가 직접 만든 파일(브로가드-내악보집.json) 한 개만 읽고 쓸 수 있습니다. 사용자의 드라이브에 있는 다른 파일·폴더에는 접근할 수 없습니다.
  • 동기화된 데이터는 사용자 본인의 구글 드라이브에만 저장됩니다. 운영자를 포함한 어떤 제3자 서버로도 전송·복사되지 않습니다.
  • 구글 로그인 토큰은 브라우저 메모리에 일시적으로만 보관되며 별도로 저장하지 않습니다.
  • 본 서비스의 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

4. 쿠키·분석 도구

본 서비스는 자체적으로 쿠키, 광고, 방문자 분석 도구를 사용하지 않습니다. 다만 웹 호스팅(Vercel)과 라이브러리 CDN 제공자가 서비스 제공을 위한 기본적인 접속 기록을 남길 수 있습니다.

5. 제3자 제공

수집하는 개인정보가 없으므로 제3자에게 제공하는 개인정보도 없습니다.

6. 데이터 삭제

브라우저 저장소의 데이터는 사용자가 브라우저의 사이트 데이터 삭제 기능으로 언제든 지울 수 있습니다. 구글 드라이브의 동기화 파일은 사용자가 자신의 드라이브에서 직접 삭제할 수 있으며, 연동 해제는 구글 계정의 서드파티 액세스 관리에서 언제든 가능합니다.

7. 문의

본 방침에 대한 문의는 구글 로그인 동의 화면에 표시된 운영자(지원) 이메일로 연락해 주세요.
