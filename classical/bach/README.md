# 요한 제바스티안 바흐 (1685–1750) — 바로크

> **음악의 아버지.** 여러 선율을 동시에 엮는 대위법과 화성을 집대성했고, 그 뒤의 모차르트, 베토벤, 쇼팽이 모두 바흐의 평균율로 공부했습니다.

## 바흐 공부 노트

### 생애

| 연도 | 곳 | 일 |
|---|---|---|
| 1685 | 아이제나흐 | 음악가 집안에서 태어남. 열 살에 부모를 모두 잃고 큰형 집에서 자람 |
| 1700–1703 | 뤼네부르크 | 성 미하엘 학교 합창단. 북독일 오르간 음악을 배움 |
| 1703–1708 | 아른슈타트 · 뮐하우젠 | 교회 오르가니스트. 1707년 마리아 바르바라와 결혼 |
| 1708–1717 | 바이마르 | 궁정 오르가니스트. 오르간 곡의 전성기 |
| 1717–1723 | 쾨텐 | 궁정 악장. **건반·기악곡의 전성기**: 평균율 1권, 인벤션, 프랑스 모음곡, 브란덴부르크 협주곡. 1720년 아내가 세상을 떠나고, 1721년 가수 안나 막달레나와 재혼 |
| 1723–1750 | 라이프치히 | 성 토마스 교회 칸토르. 칸타타, 마태수난곡(1727), 골드베르크 변주곡(1741), 평균율 2권 |
| 1750 | 라이프치히 | 세상을 떠남. 자녀 20명 중 절반 정도가 어른으로 자랐고, 그중 C.P.E. 바흐와 J.C. 바흐는 다음 시대의 유명 작곡가가 됨 |
| 1829 | 베를린 | 한동안 잊혔다가, 멘델스존의 마태수난곡 공연으로 다시 주목받음 |

### 알아 두면 좋은 말

- **BWV:** 바흐 작품 번호(Bach-Werke-Verzeichnis). "BWV Anh."는 부록, 즉 바흐 작품인지 확실하지 않은 곡들입니다.
- **평균율:** 한 옥타브를 고르게 나눈 조율. 24개 조를 모두 칠 수 있게 되어, 바흐는 모든 장조와 단조로 전주곡과 푸가를 썼습니다.
- **인벤션:** 짧은 주제를 두 손이 주고받으며 발전시키는 연습곡. 아들의 교육용으로 썼습니다.
- **모음곡:** 춤곡 모음. 알르망드, 쿠랑트, 사라방드, 지그가 기본이고 미뉴에트, 가보트 등이 끼어듭니다.
- **코랄:** 교회에서 다 함께 부르는 찬송 선율.

### 바흐를 칠 때

- 페달은 거의 쓰지 않고, 손가락으로 레가토를 만듭니다.
- 두 손이 각자 노래하는 두 사람이라고 생각하고, 왼손도 멜로디처럼 칩니다.
- 바로크의 트릴은 **윗음부터** 시작합니다. 뮤직랩의 트릴 재생도 윗음부터 시작합니다.
