# 🎼 클래식 악보집 — 음악의 역사를 따라 치는 피아노

음악의 역사 순서대로 작곡가를 한 명씩 공부하면서, 곡마다 세 단계 악보로 연습하는 악보집입니다.
악보집 앱에서는 **시대 → 작곡가 → 곡 → 단계** 순서로 찾아 들어가도록 만들 예정입니다([요청서](../docs/requests/library-classical-tree.md)).

## 세 단계

| 단계 | 어떻게 만드나 | 누구에게 |
|---|---|---|
| **1 인터미디어트** | 멜로디에 쉬운 왼손(분산화음이나 화음)을 붙입니다. 필요하면 쉬운 조로 옮기고, 반복을 줄이고, 템포를 낮춥니다. | 곡을 처음 익힐 때 |
| **2 어드밴스** | 원곡의 조와 화음, 흐름은 지키고 가장 어려운 부분(빠른 패시지, 넓은 도약, 옥타브, 3성부 이상)만 줄입니다. | 원곡으로 가는 다리 |
| **3 원곡** | 원래 조, 화음, 빠르기 그대로. 피아노곡이 아닌 원곡(관현악, 칸타타, 오르간)은 원래 악보를 피아노로 충실히 옮긴 판입니다. | 목표 |

단계의 난이도는 실제로 쳐 보신 뒤 조정합니다.

## 원칙

- **저작권이 끝난 곡만 다룹니다.** 한국 기준으로 작곡가가 1962년 이전에 세상을 떠난 곡입니다(사망 후 70년, 2013년 이전에 이미 끝난 50년 기준 포함).
- **모든 단계는 직접 편곡합니다.** 시판 편곡집이나 다른 사람의 편곡(예: 마이라 헤스의 「예수, 인간 소망의 기쁨」 편곡, 헤스는 1965년 사망)을 베끼지 않습니다.
- **원곡 단계는 기억에서 옮겨 쓴 것이라 틀린 음이 있을 수 있습니다.** 각 곡의 원곡 정확도 추정치를 목차에 적어 두었고, 이상한 곳은 저작권이 끝난 옛 악보(IMSLP 등)와 대조해 고칩니다.

## 이름 규칙

- 악보집 제목: `바흐 · 미뉴에트 G장조 [1 인터미디어트]` (카테고리는 '클래식')
- 파일: `classical/<작곡가>/<곡>-<단계번호>-<단계>.abc` (예: `classical/bach/minuet-g-anh114-1-intermediate.abc`)
- 목록 파일: [`catalog.json`](catalog.json) — 시대, 작곡가, 곡, 단계 순서의 구조
