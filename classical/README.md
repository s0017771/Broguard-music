# 🎼 클래식 악보집 — 음악의 역사를 따라 치는 피아노

음악의 역사 순서대로 작곡가를 한 명씩 공부하면서, 곡마다 두 가지 악보(리드시트, 원곡)로 연습하는 악보집입니다.
악보집 앱에서는 **시대 → 작곡가 → 곡 → 악보** 순서로 찾아 들어갑니다.

## 두 가지 악보

| 악보 | 어떻게 만드나 | 무엇을 배우나 |
|---|---|---|
| **1 리드시트** | 오른손은 원곡 멜로디(꾸밈음 등은 뺄 수 있음)에 코드 기호를 붙이고, 왼손은 그 코드로 곡의 분위기에 맞는 반주를 넣습니다. 원곡에 뚜렷한 멜로디가 없으면(펼친화음뿐인 전주곡 등) 맨 윗음을 이어 멜로디로 만듭니다. | 곡의 화성(코드 흐름)과 **반주 기법** |
| **2 원곡** | 원래 조, 화음, 빠르기 그대로. 피아노곡이 아닌 원곡(관현악, 칸타타, 오르간)은 원래 악보를 피아노로 충실히 옮긴 판입니다. | 목표 |

2026-11-21에 세 단계(인터미디어트, 어드밴스, 원곡)에서 두 가지로 바꿨습니다(사용자 요청: "세 가지 버전이 큰 의미가 없는 것 같아요").

### 리드시트의 반주 기법

곡마다 분위기에 맞는 반주를 고르고, 같은 기법이 되풀이되지 않게 해서 여러 반주법을 익히도록 합니다. 악보 첫머리 주석과 왼손 첫 음 아래 글자에 그 곡의 반주 기법을 적어 둡니다.

| 기법 | 모양 | 쓴 곡 |
|---|---|---|
| 왈츠 베이스 | 3/4박자, 1박에 베이스, 2·3박에 화음(쿵-짝-짝) | 미뉴에트 G장조 |
| 블록 코드 | 코드가 바뀔 때마다 세 음을 한꺼번에 길게, 가까운 자리바꿈으로 이어 가기 | 미뉴에트 G단조 |
| 쿵-짝 교대 베이스 | 박마다 베이스 다음에 화음, 베이스는 뿌리음과 5음을 번갈아 | 뮈제트 D장조 |
| 아르페지오 | 1-5-8-10(뿌리음, 5음, 옥타브, 3음)으로 8분음표를 펼쳐 올라가기 | 작은 전주곡 C장조 |
| 워킹 베이스 | 4분음표로 한 박에 한 음, 다음 코드로 한 음씩 걸어가듯 이어 가기 | 2성 인벤션 1번 |
| 알베르티 베이스 | 낮은음-높은음-가운데음-높은음(도-솔-미-솔)을 8분음표로 | 2성 인벤션 8번 |

## 원칙

- **저작권이 끝난 곡만 다룹니다.** 한국 기준으로 작곡가가 1962년 이전에 세상을 떠난 곡입니다(사망 후 70년, 2013년 이전에 이미 끝난 50년 기준 포함).
- **리드시트는 직접 편곡합니다.** 시판 편곡집이나 다른 사람의 편곡(예: 마이라 헤스의 「예수, 인간 소망의 기쁨」 편곡, 헤스는 1965년 사망)을 베끼지 않습니다.
- **원곡은 저작권이 끝난 옛 악보를 보고 옮깁니다.** 옛 악보가 없어 기억에서 옮겨 쓴 곡은 틀린 음이 있을 수 있으니 목차에 원곡 정확도 추정치를 적고, 이상한 곳은 옛 악보(IMSLP 등)와 대조해 고칩니다.

## 이름 규칙

- 악보집 제목: `바흐 · 미뉴에트 G장조 [1 리드시트]`, `바흐 · 미뉴에트 G장조 [2 원곡]` (카테고리는 '클래식')
- 파일: `classical/<작곡가>/<곡>-1-leadsheet.abc`, `<곡>-2-original.abc` (예: `classical/bach/minuet-g-anh114-1-leadsheet.abc`)
- 악보집 id: `classical-<곡 id>-leadsheet`, `classical-<곡 id>-original` (예전 세 단계의 id `classical-<곡 id>-1`~`-3`과 겹치지 않게)
- 목록 파일: [`catalog.json`](catalog.json) — 시대, 작곡가, 곡, 악보 순서의 구조
