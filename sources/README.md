# 원곡 대조용 공개 악보 원본 (`sources/`)

클래식 악보집을 편곡하는 세션이 원곡의 정확한 음을 확인할 수 있도록, 저작권이 끝난 악보의 **원본 파일을 그대로** 모아 둔 곳입니다. 편곡이나 수정은 하지 않았고, 파일 이름도 받은 그대로입니다. 이 브랜치(`claude/pd-sources`)는 참고 자료용이며 main에 머지하지 않습니다.

- 받은 날: 2026-11-21
- Mutopia의 `.ly`는 LilyPond 텍스트 악보이고 `.mid`는 같은 악보에서 만든 MIDI입니다. 여러 파일이 zip으로 제공된 곡은 압축을 풀어 두고 zip은 지웠습니다(내용은 동일).
- 5 MB가 넘는 파일, PDF는 받지 않았습니다.
- CC BY-SA 3.0 파일은 출처 표시와 같은 조건 공유가 필요합니다. 우리 악보집의 편곡은 음을 대조하는 데만 쓰고 이 파일을 복사해 넣지 않습니다.
