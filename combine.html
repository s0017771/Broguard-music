𝄞리듬 + 멜로디 합치기

A곡의 리듬(음 길이) + B곡의 멜로디(계이름) + 코드를 ABC 악보로 합쳐줍니다. 마디는 r 로 나눠요.

입력

낮은 옥타브 ,도 · 높은 옥타브 도' 또는 도^ · 쉼표 0 · 붙임음은 붙여쓰기 도도
한 마디에 한 코드면 C, 두 코드면 공백으로 F G(앞 코드=마디 앞부분, 뒤 코드=중간부터) · 마디 구분 r

자동 개수 맞춤: 한 마디 안에서 음과 리듬 개수가 다를 때 자동으로 맞춥니다(음 모자라면 늘리고, 넘치면 리듬을 쪼갬). 끄면 경고만 표시.

🎵 입력 방법 자세히

리듬(음 길이) — 숫자 하나가 음 하나예요. 숫자는 “가장 짧은 음”의 몇 배인지를 뜻합니다.
· 8분음표 기준: 1=8분 2=4분 3=점4분 4=2분 8=온음표
· 16분음표 기준: 1=16분 2=8분 4=4분 8=2분 16=온음표

멜로디(계이름) — 도 레 미 파 솔 라 시 (가운데 옥타브, 공백 구분).
· 낮은 옥타브 = 앞에 쉼표 ,도 (더 낮게 ,,도)
· 높은 옥타브 = 뒤에 도' 또는 도^ (더 높게 도'' · 도^^)
· 쉼표(쉬는 음) = 0 · 마디 구분 = r

붙임음(타이) — 같은 음을 붙여 쓰면 하나로 이어진 긴 음이 돼요.
· 도도 = 도를 두 칸 길이로 이어서(붙임음) · 도 도 = 도를 두 번 따로 침
· 옥타브까지 같아야 이어집니다(도도'는 이어지지 않음). 이음줄(다른 음 연결)은 악보 연구소에서 하세요.

코드 — 마디마다 코드 이름. 한 마디에 두 개면 공백으로: F G → 앞 코드는 마디 앞부분, 뒤 코드는 중간부터 붙습니다.

결과 — 4마디마다 줄바꿈

여기에 합쳐진 ABC가 나옵니다.

복사한 ABC를 악보 연구소(lab.html) 입력창에 붙여넣고 재생하세요. 엑셀은 마디별로 나눠서 수정하기 좋습니다.
